# ✈️ Oneness Airline – Flight Booking Landing Page

A modern flight booking landing page designed and implemented for academic and portfolio purposes.  
The project focuses on **UI/UX design principles** and **frontend implementation** using core web technologies.

---

## 📌 Project Overview

**Oneness Airline** is a responsive flight booking landing page that helps users quickly search and explore flight options through a clean, professional airline-style interface.

The design is built from wireframe to high-fidelity UI and then implemented as a static frontend, ready for backend integration in the future.

---

## 🎯 Objectives

- Design a clean and modern UI following airline / travel industry standards  
- Apply UI/UX principles such as visual hierarchy, spacing, and consistency  
- Build a responsive layout using Bootstrap 5 (mobile-first)  
- Practice frontend structure suitable for real-world projects  

---

## 🛠 Technologies Used

- **HTML5** – Structure and semantic markup  
- **CSS3** – Custom styling and layout adjustments  
- **Bootstrap 5** – Grid system and responsive design (mobile-first)  
- **Font Awesome** – Icons for navigation, booking form, and UI elements  

---

## ✨ Key Features

- Sticky navigation bar with brand icon and call-to-action  
- Hero section with background image and overlay  
- Flight booking form with icons and clear input fields  
- Popular destinations section with image overlay cards  
- Top airlines section to build user trust  
- Clean and structured footer with legal and contact links  
- Fully responsive on desktop, tablet, and mobile devices
